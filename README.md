## 📊 Dataset

- 284,807 transactions
- 30 features
- Binary classification: `0` = legitimate, `1` = fraud
- Highly imbalanced dataset

## 🚀 Approach

- Data exploration and preprocessing
- Feature scaling
- Logistic Regression
- Evaluation using Accuracy, Precision, F1 Score, and Log Loss

## 🎯 Goal

Part of a **from-scratch machine learning series** focused on understanding fundamental ML models.
